Blockchain & Web3 – Hướng dẫn từ cơ bản đến thực hành

February 8, 2026 · 2 min read

📌 Giới thiệu​

Blockchain và Web3 đang là những công nghệ cốt lõi của Internet thế hệ mới.
Nếu Web2 giúp người dùng tương tác và tạo nội dung, thì Web3 hướng đến mục tiêu lớn hơn:
👉 trao quyền sở hữu dữ liệu và tài sản số cho người dùng.

Bài viết này được thiết kế dành cho người mới bắt đầu, giúp bạn:

  • Hiểu Blockchain là gì
  • Hiểu Web3 khác Web2 ở điểm nào
  • Biết Smart Contract hoạt động ra sao
  • Có cái nhìn tổng quan trước khi học sâu hơn

📊 Slide minh hoạ toàn bộ bài học:
👉 Blockchain & Web3 – Canva

1️⃣ Blockchain là gì?​

Blockchain (chuỗi khối) là một cơ sở dữ liệu phân tán, nơi dữ liệu được:

  • Ghi lại thành từng Block
  • Các block liên kết với nhau bằng mã hoá
  • Không thể sửa đổi dữ liệu đã ghi

🔗 Đặc điểm chính của Blockchain​

  • Phi tập trung: Không có máy chủ trung tâm
  • Minh bạch: Ai cũng có thể kiểm tra giao dịch
  • Bất biến: Dữ liệu đã ghi gần như không thể xoá

📌 Ví dụ:

Khi bạn chuyển tiền trên blockchain, giao dịch đó sẽ được ghi lại vĩnh viễn và mọi người đều có thể kiểm tra.

2️⃣ Cấu trúc cơ bản của Blockchain & Web3​

Một hệ sinh thái Web3 thường gồm các thành phần sau:

🔹 Block​

  • Chứa dữ liệu giao dịch
  • Có mã băm (hash) của block trước

🔹 Hash​

  • Là chuỗi ký tự mã hoá đại diện cho dữ liệu
  • Chỉ cần thay đổi 1 ký tự → hash đổi hoàn toàn

🔹 Node​

  • Là các máy tính tham gia mạng blockchain
  • Mỗi node lưu một bản sao dữ liệu

🔹 Wallet (Ví Web3)​

  • Đại diện cho danh tính số của người dùng
  • Lưu private key (chìa khoá riêng)
  • Ví dụ: MetaMask, Trust Wallet

👉 Xem trên Canva

3️⃣ Smart Contract là gì?​

Smart Contract (Hợp đồng thông minh) là:

Chương trình tự động chạy trên blockchain, không cần bên trung gian.

🧠 Đặc điểm​

  • Tự động thực thi
  • Không thể chỉnh sửa sau khi deploy
  • Công khai & minh bạch

✍️ Ví dụ Smart Contract đơn giản (Solidity)​

pragma solidity ^0.8.0;

contract HelloWeb3 {
    function hello() public pure returns(string memory) {
        return "Hello Web3!";
    }
}

Website

January 15, 2026 · One min read

This website is built using Docusaurus, a modern static website generator.

Installation​

yarn

Local Development​

yarn start

This command starts a local development server and opens up a browser window. Most changes are reflected live without having to restart the server.

Build​

yarn build

This command generates static content into the build directory and can be served using any static contents hosting service.

Deployment​

Using SSH:

USE_SSH=true yarn deploy

Not using SSH:

GIT_USER=<Your GitHub username> yarn deploy

If you are using GitHub pages for hosting, this command is a convenient way to build the website and push to the gh-pages branch.

Tutorial Intro

January 15, 2026 · One min read

Let's discover Docusaurus in less than 5 minutes.

Getting Started​

Get started by creating a new site.

Or try Docusaurus immediately with docusaurus.new.

What you'll need​

  • Node.js version 20.0 or above:
    • When installing Node.js, you are recommended to check all checkboxes related to dependencies.

Generate a new site​

Generate a new Docusaurus site using the classic template.

The classic template will automatically be added to your project after you run the command:

npm init docusaurus@latest my-website classic

You can type this command into Command Prompt, Powershell, Terminal, or any other integrated terminal of your code editor.

The command also installs all necessary dependencies you need to run Docusaurus.

Start your site​

Run the development server:

cd my-website
npm run start

The cd command changes the directory you're working with. In order to work with your newly created Docusaurus site, you'll need to navigate the terminal there.

The npm run start command builds your website locally and serves it through a development server, ready for you to view at http://localhost:3000/.

Open docs/intro.md (this page) and edit some lines: the site reloads automatically and displays your changes.

Create a Blog Post

January 15, 2026 · One min read

Docusaurus creates a page for each blog post, but also a blog index page, a tag system, an RSS feed...

Create your first Post​

Create a file at blog/2021-02-28-greetings.md:

blog/2021-02-28-greetings.md
---
slug: greetings
title: Greetings!
authors:
  - name: Joel Marcey
    title: Co-creator of Docusaurus 1
    url: https://github.com/JoelMarcey
    image_url: https://github.com/JoelMarcey.png
  - name: Sébastien Lorber
    title: Docusaurus maintainer
    url: https://sebastienlorber.com
    image_url: https://github.com/slorber.png
tags: [greetings]
---

Congratulations, you have made your first post!

Feel free to play around and edit this post as much as you like.

A new blog post is now available at http://localhost:3000/blog/greetings.
